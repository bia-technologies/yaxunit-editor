# Техническое описание проекта YAxUnit Editor

## Назначение
Проект предоставляет веб‑редактор кода BSL (1C:Предприятие) с поддержкой тестов YAxUnit. Редактор построен на Monaco и включает подсказки, диагностики, семантическую модель и инструменты запуска/визуализации тестов.

## Технологический стек
- Язык: TypeScript
- Сборка: Vite (`vite.config.ts`, `vite.config.playground.js`)
- Редактор: `monaco-editor-core`
- Парсинг BSL: `chevrotain`, `lezer-bsl`
- Тесты: Vitest (`vitest.config.ts`)

## Архитектура (высокий уровень)
- Входная точка: `src/main.ts`
- Редактор BSL и модель модуля: `src/bsl/editor`, `src/bsl/moduleModel.ts`, `src/bsl/lezer`
- Семантическая модель и типизация: `src/bsl/codeModel`, документация `docs/codemodel.md`
- Контексты (scopes) для IntelliSense: `src/bsl/scope`, документация `docs/scopes.md`
- Интеграция YAxUnit: `src/yaxunit`
- Запуск тестов и отображение результатов: `src/yaxunit/features`
- Модель тестов и резолвер сценариев: `src/yaxunit/test-model`, `src/yaxunit/test-resolver`
- Интеграция с 1C V8 web‑app: `src/onec/V8Proxy.ts`

## Ключевые компоненты
- `BslEditor` (`src/bsl/editor/editor.ts`): создание Monaco‑редактора, регистрация хоткеев, подключение модели и контекстов.
- `YAxUnitEditor` (`src/yaxunit/editor.ts`): расширяет `BslEditor`, добавляет резолвер тестов, декораторы статуса, маркеры ошибок и команды запуска тестов.
- `LezerModuleModel` (`src/bsl/lezer/moduleModel.ts`): адаптер модели Monaco к парсеру Lezer для BSL.
- `CodeModel` (`src/bsl/codeModel`): семантическое дерево символов, расчет типов и переменных; обновление инкрементально или полной пересборкой (см. `docs/codemodel.md`).
- Scopes (`src/bsl/scope`): уровни контекстов для подсказок и поиска символов (см. `docs/scopes.md`).

## Потоки данных
- Редактирование кода в Monaco инициирует обновление модели.
- Парсер и фабрика моделей обновляют `CodeModel` (полная или инкрементальная схема).
- После пересчета типов и контекстов обновляются подсказки, навигация и диагностики.
- Для тестов: резолвер сценариев строит модель тестов; UI‑слой отображает статусы, ошибки и стек вызовов.

## Интеграция с 1C:Предприятие
- `V8Proxy` обеспечивает обмен событиями между JS‑редактором и окружением 1C через DOM‑форвардеры событий.
- Используется для запуска тестов и получения результатов выполнения.

## Сборка и запуск
- `pnpm dev` — локальная разработка.
- `pnpm build` — сборка (TS + Vite).
- `pnpm dev-playground` / `pnpm build-playground` — режим/сборка песочницы.
- `pnpm test` — прогон Vitest.

## Нефункциональные требования и ограничения
- Редактор ориентирован на браузерный запуск.
- Производительность подсказок и типизации зависит от инкрементального обновления `CodeModel`.
- Контекстное индексирование конфигурации 1C частично запланировано и может расширяться.
